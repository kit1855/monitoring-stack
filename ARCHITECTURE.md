# Архитектура мониторинга

## Общая схема

Система мониторинга построена по классической схеме: сбор метрик → хранение → визуализация → алертинг.

## Схема трафика

Node Exporter (порт 9100) → Prometheus (порт 9090) → Grafana (порт 3001)

Prometheus (порт 9090) → Alertmanager (порт 9093) → Email (SMTP)

## Компоненты и порты

- Node Exporter: порт 9100 (сбор метрик с сервера)
- Prometheus: порт 9090 (сбор и хранение метрик)
- Grafana: порт 3001 (визуализация)
- Alertmanager: порт 9093 (алерты и уведомления)

## Потоки данных

1. Node Exporter собирает метрики (CPU, RAM, диск, сеть)
2. Prometheus опрашивает Node Exporter каждые 15 секунд
3. Grafana подключается к Prometheus и показывает дашборды
4. Prometheus проверяет правила алертов каждые 30 секунд
5. При срабатывании алерта Prometheus отправляет его в Alertmanager
6. Alertmanager отправляет email-уведомление

## Правила алертов

- HighCPUUsage: CPU выше 80% в течение 5 минут
- DiskUsageHigh: свободно менее 10% на диске
- ServiceDown: Node Exporter не отвечает 1 минуту
